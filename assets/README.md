# Assets

All files here were made for this kit. None are Microsoft files.

| File | What it is |
|---|---|
| `xp_start_button.png` | 48x120 start button sprite for Open-Shell (3 stacked 40px states: normal, hover, pressed). A lookalike drawn for this kit. |
| `xp_style_wallpaper.jpg` | 1280x720 AI-generated "rolling green hill, blue sky" wallpaper in the spirit of Bliss. Not Microsoft's Bliss photograph. Windows scales it to fill larger screens. |
| `xp_flag.ico`, `xp_flag_64.png` | Four-color waving flag icon drawn for this kit. |

Windows, Windows XP, Bliss and Luna are trademarks or artwork of Microsoft.
This project is not affiliated with or endorsed by Microsoft. Want a sharper
wallpaper? Drop your own `xp_style_wallpaper.jpg` here before running
Install-XPTheme.ps1.
